# Credit Card Fraud Detection Using Machine Learning

## Overview
This project applies machine learning techniques to detect fraudulent credit card transactions using transaction-based datasets.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- LightGBM
- Matplotlib
- Jupyter Notebook

## Features
- Data preprocessing
- Class imbalance handling using SMOTE
- Fraud detection model training
- Model comparison and evaluation
- ROC curve analysis
- Performance visualization

## Models Used
- Logistic Regression
- Random Forest
- Support Vector Classifier (SVC)
- XGBoost
- LightGBM

## Results
The project compares multiple machine learning algorithms and evaluates their effectiveness in detecting fraudulent financial transactions.
